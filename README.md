# Python Mini-Projects & Math Scripts

A collection of lightweight Python scripts focusing on mathematical sequences, functions, and data visualization using Matplotlib.

## Projects Included

* **Collatz Sequence:** Calculates and plots the step-by-step path of any user-provided integer down to 1 using the 3x+1 rules.
* **Fibonacci Series:** Computes the standard Fibonacci progression up to a user defined number of terms and plots the growth curve.
* **Prime Number Finder:** Identifies all prime numbers up to a specified upper bound limit and displays them visually.
* **Random Number Guessing Game:** A terminal-based game where the user gets exactly 3 credits to guess a randomly chosen integer between 0 and 100.
* **Riemann Zeta Function:** Computes and plots the terms of the Riemann zeta function for user-defined variables (restricted to real numbers).

## 🛠️ Prerequisites & Installation

To run the visualization scripts, you will need Python installed along with the `matplotlib` library. 

You can install the required package using pip:

```bash
pip install matplotlib
```

## How to Run

1. Clone or download this repository.
2. Open your terminal or IDE inside the project folder.
3. Run any script directly using Python:

```bash
python collatz_sequence.py
python fibonacci_series.py
python prime_finder.py
python guessing_game.py
python riemann_zeta.py
```
